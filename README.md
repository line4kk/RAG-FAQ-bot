# Telegram RAG FAQ Bot

Telegram-бот для ответов на вопросы пользователей с использованием Retrieval-Augmented Generation (RAG).

Бот принимает свободные текстовые вопросы, находит релевантные записи в базе знаний и использует модель Gemini для генерации итогового ответа на основе найденного контекста.

Проект реализован на примере виртуального консультанта фитнес-клуба, но может быть адаптирован под любую предметную область.

---

## Почему это полезно для бизнеса

Традиционные FAQ-системы требуют точного совпадения формулировки вопроса с заранее заданными шаблонами. Это создает трение для пользователя и увеличивает нагрузку на поддержку.

Данный подход решает эти проблемы:

- Пользователь **может задавать вопрос в свободной форме**, без подбора формулировки
- Система находит релевантные ответы даже при разных формулировках и синонимах
- Бот **не выдумывает ответы**, а опирается только на данные из базы знаний (снижение риска галлюцинаций)
- Снижается количество обращений к живым операторам
- Ускоряется получение ответа пользователем

Практическая ценность:

- ↓ Снижение нагрузки на поддержку
- ↑ Удовлетворенность пользователей за счет быстрых ответов
- ↑ Конверсия (пользователь быстрее получает нужную информацию)

RAG-подход позволяет приблизить FAQ-систему к уровню живого консультанта без необходимости хранить тысячи сценариев и кнопок.

## Пример работы

Пример базы `faq.tsv`:

```text
Какие виды абонементов доступны в клубе Diamond?	Мы предлагаем базовый, премиум и VIP абонементы с различным уровнем доступа к залу, групповым занятиям и персональным тренировкам.
Какие часы работы клуба?	Клуб открыт ежедневно с 6:00 до 23:00, включая выходные и праздники.
Сколько стоит абонемент?	Стоимость начинается от 10000 рублей в месяц, в зависимости от выбранного тарифа и срока. Более подробную информацию о ценах Вы можете уточнить в отделе продаж.
```

*Бот корректно ответил, несмотря на различие формулировок вопроса (semantic + keyword поиск).*

## Стек технологий

**Backend:**

- Python
- aiogram 3 — фреймворк для Telegram-ботов
- SentenceTransformers — эмбеддинги для поиска по смыслу
- FAISS — векторный поиск ближайших соседей
- pymorphy3 — лемматизация для keyword-поиска
- NumPy — обработка числовых данных и эмбеддингов

**Модели:**

- Embedding-модель: `paraphrase-multilingual-MiniLM-L12-v2`
- LLM: `gemini-2.5-flash`

**LLM:**

- Google Gemini API — генерация ответа на основе найденного контекста

**Хранение данных:**

- TSV — хранение базы FAQ
- JSON — список администраторов

**Прочее:**

- python-dotenv — работа с переменными окружения и секретами

## Функционал

- Telegram-бот на `aiogram 3`
- Поддержка свободного ввода (без кнопок и сценариев)
- Админ-панель для загрузки новой базы FAQ
- Хранение FAQ в `.tsv` формате
- Гибкая архитектура RAG-пайплайна
- Безопасная работа с API-ключами через `.env`

## RAG Pipeline

В проекте реализован собственный комбинированный подход к поиску релевантных ответов:

### 1. Поиск по ключевым словам (keyword retrieval)

- Нормализация текста
- Лемматизация через `pymorphy3`
- Поиск по пересечению слов

### 2. Семантический поиск (semantic retrieval)

- Генерация эмбеддингов через `SentenceTransformer`
- Поиск ближайших соседей через `FAISS`
- Фильтрация по порогу релевантности

### 3. Формирование контекста для модели

- Найденные FAQ-записи передаются в модель как контекст

### 4. Генерация ответа

- Ответ формируется моделью Gemini на основе найденных данных
- Если релевантных записей нет — бот просит переформулировать вопрос

## Установка

### 1. Создайте виртуальное окружение

```powershell
python -m venv venv
.\\venv\\Scripts\\activate
```

### 2. Установите зависимости

```powershell
pip install -r requirements.txt
```

### 3. Настройте переменные окружения

```powershell
copy .env.example .env
```

```env
TOKEN=your_telegram_bot_token
GEMINI_API_KEY=your_gemini_api_key
```

## Файлы данных

Создайте рабочие файлы на основе примеров:

```powershell
copy data\faq.example.tsv data\faq.tsv
copy data\admin_list.example.json data\admin_list.json
```

### FAQ формат (`faq.tsv`):

```text
Вопрос<TAB>Ответ
```

Пример:

```text
Какой график работы?	Клуб работает ежедневно с 8:00 до 22:00.
```

### Формат `admin_list.json`

Файл содержит список Telegram ID пользователей, которым доступна админ-панель.

Формат — JSON-массив строк:

```json
[
  "123456789",
  "987654321"
]
```

ID пользователя можно узнать через бота @userinfobot или аналогичные сервисы.

Только пользователи из этого списка могут использовать команды админ-панели (`/admin`, `/upload`).

## Запуск

```powershell
python bot.py
```

При первом запуске модель эмбеддингов будет автоматически загружена. Это может занять некоторое время.

## Команды бота

- `/start` — начать работу
- `/admin` — админ-панель
- `/upload` — загрузка новой FAQ-базы
- `/exit` — выход из админ-режима

## Будущие улучшения

- Возможность переключения на живого оператора в случае отсутствия ответа или низкой уверенности модели. Это важно, так как бот не генерирует информацию "из головы", а опирается только на данные из базы знаний.
- Проведение тестов и подбор оптимальных параметров retrieval (threshold, количество результатов, баланс keyword/semantic поиска) для повышения точности ответов.
- Добавление контекстного режима диалога, чтобы бот учитывал предыдущие сообщения пользователя и поддерживал более естественное общение.
- Универсализация бота: добавление интерфейса/настроек для подключения новой базы знаний без изменения кода, что позволит использовать решение в разных доменах.
